# Screenshots

Placeholder directory for the images referenced in the root [README](../README.md#-screenshots).

Drop the following files here (exact names — the README links to them by path). The
folder is tracked via `.gitkeep`; the images themselves are not committed yet.

| File                    | What to capture                                              | Suggested size  |
| ----------------------- | ------------------------------------------------------------ | --------------- |
| `landing.png`           | Landing page hero + features grid                             | 1440x900         |
| `dashboard-dark.png`    | `/app` dashboard, dark theme, with sample stat cards           | 1440x900         |
| `dashboard-light.png`   | Same dashboard in the warm parchment light theme               | 1440x900         |
| `jobs.png`              | `/app/jobs` list with search + status filters active          | 1440x900         |
| `job-detail.png`        | `/app/jobs/:id` detail / edit form                             | 1440x900         |
| `cv-manager.png`        | `/app/cvs` dropzone + uploaded CV cards                       | 1440x900         |
| `settings.png`          | `/app/settings` import/export panel                           | 1440x900         |
| `mobile.png`            | Any page on a phone viewport with the hamburger sidebar open   | 390x844          |

Tips for good-looking captures:

- Seed a few realistic (fake) applications first so the dashboard isn't empty.
- Use dark mode for most shots, light mode for the theme-proof shot.
- Browser zoom at 100%, devtools closed.
- Blur or replace any real personal data — this is a public repo.
